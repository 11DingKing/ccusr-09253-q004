# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 导师确认委托链

实习签到必须由学生的责任导师确认；导师出差时可把指定学生在某个有期限的窗口内委托给另一位老师，受托人可继续向下转授，形成**有期限、不可循环**的委托链。

- 委托窗口为半开区间 `[starts_at, ends_at)`，时间戳统一以 UTC 比较，可按任意 IANA 时区提交。
- 创建委托时校验：不得自我委托、委托人必须实际持有确认权、同窗口不得并行重复授权、授权关系图不得成环。
- 撤销只对撤销时刻**之后**生效；撤销或过期都不影响已经合法落库的确认（撤销不溯及既往）。
- 每条确认记录与对应的 `mentor_confirm` 事件都固化实际操作人、原责任导师、委托单号、授权版本和完整委托链。
- 批量确认为两阶段提交：先整批校验（签到存在、确属实习、未重复确认、操作人在有效链上且未过期），任一条失败则整批拒绝、不写任何数据。
- 写路径通过 `BEGIN IMMEDIATE` 串行化，并发的撤销与确认只有一种先后次序，不存在"读到旧授权后落库"的窗口。

接口（均位于 `/api`）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| PUT | `/plans/{plan}/students/{student}/mentor` | 登记/变更学生的责任导师 |
| POST | `/plans/{plan}/delegations` | 新增有期限委托（含转授权与成环校验） |
| POST | `/delegations/{grant_id}/revoke` | 撤销委托（委托人或责任导师） |
| GET | `/plans/{plan}/delegations` | 委托列表（可按学生/老师过滤） |
| GET | `/delegations/{grant_id}` | 委托详情与不可变版本历史 |
| GET | `/plans/{plan}/students/{student}/authorization?actor_mentor_id=...&at=...` | 权限查询（可指定历史时刻） |
| POST | `/plans/{plan}/confirmations` | 批量确认，全部成功或全部不落库 |
| GET | `/plans/{plan}/confirmations/{checkin_event_id}/explain` | 确认解释：操作人/责任人/授权版本、当时与当前是否授权 |

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

```bash
python3 -m pytest -q
```

## 编译检查

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询；运行过程中不需要单独的数据库或网络服务。
